# Insider Ultra Desktop — atualizações

Canal público assinado de atualizações do Insider Ultra Desktop.

Este repositório contém somente o instalador vigente, sua assinatura do updater,
o manifesto `latest.json` e a identificação do código-fonte de origem. O código
do produto permanece no repositório privado oficial.

A assinatura do updater deve ser validada pelo aplicativo antes da instalação.
